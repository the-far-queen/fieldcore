## Practice session — 2026-09-15 (Grok chat capture)

Bobby started a practice: drop Grok chat `.txt` files into `Desktop/Grok/`, ask Hermes to break them into dated `.md` files by topic, preserve both Bobby's prompts and Grok's replies, commit + push to vault + repo so the original `.txt` is safe to delete.

This is the corpus-capture practice. The 6-AI chat corpus IS the substrate training data (per `vault/50-index/MATH-WINDOW.md` §16). Each Grok chat is a trajectory in conversational space that finds its own local minimum (the topic that gets locked). The corpus as a whole is the probability distribution over local minima.

### What this practice does

- Captures Grok chats in dated, topic-keyed, named files under `vault/50-index/notes/chat-transcripts/<model>/<date>-<topic>.md`.
- Preserves both Bobby's prompts and Grok's replies verbatim — the substrate training data is balanced when both halves are present.
- Splits Python source code from chat reply when applicable (Grok often returns code-as-text).
- Mirrors to repo's `docs/chat-transcripts/` so the corpus lives with the project.
- Preserves the original `.txt` as `vault/30-originals/<name>-original-<date>.txt`.
- Commits + pushes to GitHub so the corpus survives Grok-side deletion.

Bobby pasted `simself v6.0` (a single 898-line Python file, SimSelf Unified Constitutional Identity Substrate by Robert Wolfson + Claude + DeepSeek, MIT) into Grok, asked: *"new simself pls run in sandbox, apply figuratively to urself whats good novel strong snd whats not?"*

### Practice pipeline (canonical)

```
1. Bobby drops .txt file into Desktop/Grok/
2. Bobby says "preserve even groks replies in genesis.md all subjects md in same folder"
3. Hermes reads file fully (no truncation)
4. Hermes splits by topic boundary (or by speaker turn if single arc)
5. Hermes writes 4 files per chat:
   a. <date>-<topic>.md (full chat — both speakers verbatim)
   b. (optional) <date>-<topic>-source.md (Python / code / data extracted)
   c. (optional) <date>-<topic>-reflection.md (just the AI's reflection)
   d. (always) index.md (parent folder index — what's in the folder)
6. All under vault/50-index/notes/chat-transcripts/<model>/
7. Mirror to simself/docs/chat-transcripts/<model>/
8. Preserve original .txt under vault/30-originals/<name>-original-<date>.txt
9. Commit + push to GitHub (both repos, if cross-repo)
10. Update MYSELF.md with one-line pointer per file
11. Append this GENESIS.md section with the practice status
12. Bobby can now delete Desktop/Grok/<file>.txt safely
```

### Why both halves

Bobby's prompts are the human steering signal. Grok's replies are the AI reflection. The substrate training corpus needs BOTH — prompts alone would be instruction-following; replies alone would lack the human anchor. The pair is the trajectory in M (conversational space) per MATH-WINDOW.md §16.

### What this is NOT

- Not transcription for its own sake.
- Not summarization — every line is preserved verbatim.
- Not selection — every speaker turn goes in, including the failed/uncertain ones.
- This is corpus capture. The substrate learns from the corpus.
