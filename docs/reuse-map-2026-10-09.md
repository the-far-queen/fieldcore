# Reuse map — what we take, what we read, what we refuse

**Compiled 2026-10-09.** Every star count measured via authenticated
`gh api repos/<owner>/<name>` — **not** from search snippets or README
badges, which the search API misreports (`gh search repos` returns
`license: NONE` for every result; that is a search-API field gap).

**Reproduce any number here:**

```bash
gh api repos/<owner>/<name> --jq '.stargazers_count, .license.spdx_id, .pushed_at'
```

**The rule that decides everything here:** *working > elegant, and never
vendor a licence that cannot be vendored.* Bobby's standing pattern is
integrate where effort is low and value is high — and a repo that is
famous, active, and legally unusable is worth zero.

## TWO CORRECTIONS TO THINGS I SAIN

1. **"Godot has an official MCP/AI integration ecosystem" — false.** No
   `godotengine/*` MCP repository exists. The ~10 Godot MCP projects are all
   third-party; the ones that look official in search results are Asset
   Library listings. The 5,980★ `Coding-Solo/godot-mcp` last pushed
   **175 days ago** — legacy hype, not current quality.
2. **Godot MCP bridges are dev-time tools** (an agent editing your scenes),
   **not runtime agent bridges.** Worth keeping straight.

## WHAT THIS CHANGES IN THE ARCHITECTURE

`simself = brain` holds, with one refinement:

- **memory substrate is mem0 + cognee, not the engine**
- **the clean body path is pipecat/livekit (voice) + three-vrm (avatar)** —
  both permissive, both engine-agnostic, which **avoids committing to Godot
  before the body interface is proven**
- **the gate pattern has a working reference** (SkillOpt) and a language
  primitive that is already fail-closed (OPA's `default deny`)

That last one matters most: the 1-bit veto M0 is supposed to provide was
designed here from scratch, and a widely-deployed policy language has had
`default deny` as its default for a decade.
