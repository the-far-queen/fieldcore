# Geometry Research Method

Sourced 2026-09-05 from Bobby's notes. The method itself, distilled. The 10 examples (smoke/rust/bubbles/...) are kept as illustration only — most contain numerology dressed as engineering. The **method** is the load-bearing part.

## The method

1. **Observation** — pick an obvious, everyday phenomenon (high "MUM" = "mum, ubiquitous, mundane")
2. **Strip material** — remove the specific substance/chemistry, keep only the geometric/spatial behavior
3. **Geometric decode** — what invariant or natural-law pattern is the phenomenon exhibiting?
4. **MUM check** — does this pattern appear at many scales, in many domains?
5. **Secret connection** — what does this pattern reveal that the conventional view hides?
6. **Engineering application** — can this be built, measured, reproduced?

## What survives verification

- Plateau's 120° bubble-junction angle: real (Plateau 1873)
- Fibonacci phyllotaxis in sunflower spirals: real
- Sleep ~90-minute cycles: real
- Seifert fibration structure in vortices: real (mathematical structure, not universal claim)
- Soap film = minimal surface = harmonic component: real
- Crack branching angles in materials: real (varies by material, not universal)

## What is numerology, not engineering

- Rust = (2,3) sheave because Fe₂O₃ has 2 iron + 3 oxygen: wordplay, not causation
- "26 = prime winding completeness" for iron: numerology
- Brain sulci = "fractal crack pattern in (2,3) hexagonal geometry": pattern-matching, not measured
- Pineal gland = "4D projection center of brain's constitutional manifold": unverified
- Pyramid + sarcophagus = constitutional sleep machine: speculative
- Dead Sea = "natural quantum mirror": speculative

## What the research AI should do

Bobby's directive 2026-09-05: build a research AI that scans GitHub, HuggingFace, arxiv daily. **Pull snippets of proven code. Don't rebuild wheels.**

The geometry research method is the **filter** the scanner applies. For each observed phenomenon:

1. MUM check — does it appear at multiple scales?
3. **Search existing implementations**: GitHub code that solves the geometric problem directly
4. **Pull, don't build**: re-use, don't reinvent

Scanner workflow:
```
arxiv daily digest → extract geometric claims
  → for each claim:
    → GitHub search for [phenomenon] [geometric operation]
    → HuggingFace search for related models/datasets
    → rank by: existing implementations > claimed results > speculation
  → deliver: snippet + repo link + verification status
```

**Engineering snippets already exist** for most of the real claims:
- Plateau's laws → soap film simulators (real, multiple repos)
- Phyllotaxis → sunflower seed packers (real, multiple repos)
- Crack simulation → peridynamics, phase-field fracture (real, well-cited)
- Soap film minimal surface → Surface Evolver (well-known)
- Sleep cycle / glymphatic → no engineering repo (it's biological measurement)

**The scanner is curator, not inventor.** Its job: find existing work, score against the geometric pattern, deliver proof-of-existence.

## What this is not

- Not a "discovery engine" — phenomena are already known
- Not a code generator — repos exist
- Not a theory engine — theory is already in papers
- It IS: a curator + score + aggregator of existing work, applied to the geometric lens
