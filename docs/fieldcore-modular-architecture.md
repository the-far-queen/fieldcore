## Module 11 — PSB (Primitive/Primal Semantic Blocks)

Atomic cognitive units. Not symbols, tokens, or words.

PSB tuple: (A, ΔW, ΔS, τ)
- A = action primitive or micro-sequence
- ΔW = observed world change
- ΔS = self perturbation
- τ = temporal span

Properties: grounded, repeatable, compressible, composable, bounded.

Pre-linguistic examples: contact, separation, resistance, containment, balance, transfer, obstruction.

Formation rule: PSB created iff (1) action-reaction loop repeats, (2) perturbation magnitude decreases, (3) governor approves stability.

## Module 12 — Language Acquisition (Non-Symbolic First)

Language does not create meaning. Language indexes PSBs and PSB compositions.

Verbs → PSB bundles. "put" = containment + release + stability. "take" = grasp + transfer + possession-change.

Nouns → persistent invariant clusters. Object = PSBs surviving across contexts. Identity = temporal persistence, not label.

Polysemy resolves via contextual PSB activation + governor coherence + self-alignment.

## Module 13 — Higher Reasoning (No Tokens)

Reasoning = recursive invariant manipulation under constraints. Not chains of thought, not symbol rewriting, not logical proof trees.

Mechanism: sample local field → activate relevant PSBs → apply operators (compress, negate, compose) → governor validates → write new invariant.

Counterfactual = simulated action without execution.

## Module 14 — Accelerated Learning

Fast because: no label search, no reward shaping, no backprop over large nets, locality enforced, bounded primitives.

LLM bootstrap (optional): LLMs may propose PSB candidates, suggest compositions, label invariants linguistically. LLMs may NOT write directly to field, modify self, or override governor. **This rule is real engineering** — agent design pattern.

## Module 15 — Academic Domain Ingestion (Granular)

Each field has implicit PSBs already.
- Physics: conservation, force, constraint, symmetry
- Math: equivalence, transformation, continuity, boundary
- Biology: regulation, adaptation, feedback, homeostasis

Pipeline: parse (LLM-assisted) → extract invariants → test via simulation → governor validates → store.

## Module 16 — Tool Use Beyond LLMs

Tools = actuators + sensors. API call = action, response = world reaction.

n8n provides deterministic execution, auditable workflows, side-effect isolation. Governor mediates all calls.

Each tool: confidence score, latency profile, failure PSBs. Tools become known affordances.

## Module 17 — Multi-Self / Swarm

Each agent: local self (S_i), local field slice (F_i). Only validated invariants propagate. Gossip-style, confidence-weighted merging, conflict resolution via governor consensus.

No hive mind, no central controller. Coherence via shared constraints, common physics, bounded communication.

## Module 18 — Governor (Extended)

Stack: numerical bounds → stability metrics → self-alignment → cross-agent consistency → tool safety → resource limits.

Failure modes prevented: symbol drift, runaway abstraction, self-model delusion, tool hallucination, emergent goal corruption.
